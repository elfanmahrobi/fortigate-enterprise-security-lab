# Security Policy

## Scope

This repository contains fictional and sanitized FortiGate laboratory
configurations created for educational and portfolio purposes.

## Reporting a Security Issue

If you identify any of the following issues, please report them privately:

- Exposed credentials
- Private keys
- Authentication tokens
- Real public IP addresses
- Production configuration
- Customer or employer information
- Personally identifiable information
- Unsafe configuration examples

Please do not disclose sensitive findings through a public GitHub issue.

## Supported Content

This repository does not represent a production product and does not provide
commercial support.

Security-related corrections to documentation and sanitized configuration
examples are welcome.

## Disclosure Statement

All systems, organizations, addresses, domains, and credentials shown in this
repository are fictional or reserved for documentation use.
